# Proyek CRUD Data Produk

**Tema Proyek:** Data Produk
Untuk Management data produk buah buahan bisa juga yang lain
**Fitur:**
- Create: Tambah produk dengan upload foto.
- Read: Menampilkan tabel produk dengan thumbnail.
- Update: Mengubah informasi produk dan/atau foto.
- Delete: Menghapus data beserta file fisiknya.
